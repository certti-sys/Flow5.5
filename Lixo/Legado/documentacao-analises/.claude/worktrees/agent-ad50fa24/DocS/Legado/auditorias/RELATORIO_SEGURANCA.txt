1. AUTENTICAÇÃO - VULNERABILIDADES ENCONTRADAS
=================================================================

VULNERABILIDADE CRÍTICA #1: Tokens Armazenados em localStorage
- Arquivo: src/hooks/useAuth.tsx
- Risco: XSS pode extrair tokens JWT
- Impacto: Acesso não autorizado à conta do usuário
- Severidade: CRÍTICA (CVSS 8.1)

VULNERABILIDADE CRÍTICA #2: Sem Rate Limiting
- Arquivo: src/pages/Login.tsx
- Risco: Brute force attack ilimitado
- Impacto: Força bruta contra credenciais
- Severidade: CRÍTICA (CVSS 7.5)

PROBLEMA: Tokens JWT no localStorage
- LocalStorage é vulnerável a XSS
- JavaScript malicioso pode acessar localStorage.getItem()
- Recomendação: Usar httpOnly cookies em vez de localStorage

2. AUTORIZAÇÃO - VULNERABILIDADES ENCONTRADAS  
=================================================================

VULNERABILIDADE CRÍTICA #3: Autorização Apenas no Frontend
- Arquivo: src/components/AdminProtectedRoute.tsx
- Risco: Verificação de admin apenas no React
- Impacto: Atacante pode chamar APIs diretamente
- Severidade: CRÍTICA (CVSS 8.8)
- Exemplo: curl /admin/api pode ignorer frontend check

Código vulnerável:
  if (!isAdmin) return <Navigate to="/dashboard" replace />;

Isso é apenas UI. Não protege APIs reais.

RECOMENDAÇÃO: Implementar Row Level Security (RLS) no Supabase
- Adicionar políticas RLS em TODAS as tabelas
- Validar permissões no backend antes de retornar dados
- Frontend é apenas para UX, backend é segurança real

4. API & REQUISIÇÕES - VULNERABILIDADES ENCONTRADAS
=================================================================

VULNERABILIDADE CRÍTICA #5: CORS Muito Permissivo
- Arquivo: supabase/functions/_shared/cors.ts
- Risco: Qualquer site pode fazer requisições
- Impacto: Requisições entre domínios sem restrição
- Severidade: CRÍTICA (CVSS 8.2)

Código vulnerável:
  'Access-Control-Allow-Origin': '*'  // Aceita QUALQUER origem

Recomendação - Whitelist de origens:
  const allowedOrigins = [
    'https://seu-dominio.com',
    'https://app.seu-dominio.com'
  ];
  
  return {
    'Access-Control-Allow-Origin': allowedOrigins.includes(origin) ? origin : 'null'
  };

PROBLEMA: Sem Validação de Permissões em APIs
- Arquivo: supabase/functions/payment-ops/index.ts
- Risco: Qualquer usuário pode criar pagamentos
- Impacto: Fraude de pagamento, acesso não autorizado
- Recomendação: Verificar permissões antes de processar

PROBLEMA: Falta de Rate Limiting
- Arquivo: supabase/functions/*
- Risco: DDoS, brute force
- Impacto: Função pode ser chamada ilimitadamente
- Recomendação: Implementar rate limiting por IP/user

VULNERABILIDADE CRÍTICA #6: Logs Expõem Dados Sensíveis
- Arquivo: supabase/functions/webhooks-ingest/index.ts
- Risco: Console.log expõe headers, payloads
- Impacto: Tokens, informações sensíveis nos logs
- Severidade: CRÍTICA (CVSS 7.5)

Exemplo vulnerável:
  console.log('Headers:', JSON.stringify(headers));  // Pode ter tokens!
  console.log('Payload:', JSON.stringify(payload));  // Dados sensíveis
