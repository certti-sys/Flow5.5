## 🆘 Troubleshooting

### Problema: Edge Function não deploya
```bash
# Verificar logs
supabase functions logs validate-coupon

# Verificar sintaxe
deno check supabase/functions/validate-coupon/index.ts
```

### Problema: Migration falha
```bash
# Reverter última migration
supabase db reset

# Verificar SQL
cat supabase/migrations/YYYYMMDDHHMMSS_*.sql
```

### Problema: RLS bloqueando queries
```bash
# Verificar policies no Supabase Studio
# http://localhost:54323

# Testar query com bypass RLS (apenas dev)
supabase db query "SELECT * FROM coupons" --bypass-rls
```

### Problema: TypeScript errors
```bash
# Regenerar tipos Supabase
supabase gen types typescript --local > src/integrations/supabase/types.ts

# Verificar erros
npm run build
```
